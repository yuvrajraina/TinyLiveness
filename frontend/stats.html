Production caveat

Do not treat this as a universal production guarantee. The APCER 1% policy is now set to 0.99 and should be validated again on a larger untouched and cross-domain test set before production claims.

  • Keep threshold tuning on train/dev data in future runs
  • Evaluate target cameras, screens, print media, and lighting
  • Report subgroup APCER/BPCER when metadata exists
  • Use manual review or step-up verification for uncertain cases
